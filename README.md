# Machine Learning Track

This repository contains my beginner-level Machine Learning practice projects completed as part of my Agentic AI learning journey.

## Projects

### 1. Salary Prediction Using Linear Regression

- **Objective:** Predict salary based on years of work experience.
- **Algorithm:** Simple Linear Regression
- **Libraries:** Python, Pandas, Seaborn, Matplotlib, Scikit-learn
- **Files:** `Salary.ipynb`, `Salary_Data.csv`

### 2. Health Insurance Cost Prediction

- **Objective:** Predict medical insurance charges using available customer information.
- **Algorithm:** Multiple Linear Regression
- **Libraries:** Python, Pandas, Scikit-learn
- **Files:** `health_insurance.ipynb`, `Health_insurance.csv`

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
